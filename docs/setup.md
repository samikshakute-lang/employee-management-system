## Prerequisites

- Runtime/tooling for the selected stack (TBD)

## Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/samikshakute-lang/employee-management-system.git
   cd employee-management-system
   ```
2. Install dependencies (TBD).
3. Configure environment variables (TBD).
4. Start the application (TBD).

## Environment Variables

Create a local environment file when the stack is defined. Example:

```text
# .env.example (placeholder)
APP_ENV=local
```
