# Contributing

Thanks for contributing to Employee Management System.

## Getting Started

1. Clone the repository.
2. Create a feature branch from the default branch.
3. Make focused changes with clear commit messages.
4. Add or update tests/docs as needed.
5. Open a pull request.

## Branch Naming

Use descriptive branch names, for example:

- `feature/employee-crud`
- `fix/auth-role-check`
- `docs/setup-guide`

## Pull Requests

- Fill out the PR template.
- Describe the problem, solution, and testing performed.
- Keep PRs small and reviewable where possible.
- Ensure checks pass before requesting review.

## Code Quality

- Follow the project style/lint rules once the stack is selected.
- Add tests for new behavior and bug fixes.
- Avoid committing secrets, credentials, or local environment files.

## Reporting Issues

Include:

- Clear summary
- Steps to reproduce
- Expected vs actual behavior
- Logs/screenshots when relevant
